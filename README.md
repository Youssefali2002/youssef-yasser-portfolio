## Selected work

- [WhatsApp Order Automation](https://youssefali2002.github.io/youssef-yasser-portfolio/#desktop-automation) — desktop workflow demonstration.
- [Product & Inventory Management](https://github.com/Youssefali2002/Youssef-CRUDS-App) — a bilingual JavaScript dashboard.
- [Zad Al-Qulub](https://youssefali2002.github.io/youssef-yasser-portfolio/#zad-al-qulub) — independent mobile app with the complete Quran, daily adhkar, prayer times, and adhan alerts with offline audio. [Releases](https://github.com/Youssefali2002/zad-al-qulub-updates).

## Local preview

Run `python -m http.server 8080` from the repository root and open `http://localhost:8080/`. GitHub Pages serves the static files directly. The English and Arabic pages share `assets/portfolio.css`.
